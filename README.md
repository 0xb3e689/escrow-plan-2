A 279-character plan that an AI agent can carry out by itself: turn $100 into
the most money possible in 30 days by working escrowed bug bounties on
algora.io. Day 1 buys the agent its own labor ($70 of LLM credits) and a test
bench ($30 of VPS), then one disciplined PR per day — claim only after the fix
lands and the tests are green — compounds to a median of 7 merges, or $700, by
day 30, with every payout half reinvested in more credits so claims run in
parallel. Five straight rejects means the stack is wrong, and it pivots.

## Run it

```
python3 main.py
```

The program writes the plan to `/output/entry.txt` as one UTF-8 line of 279
code points with no trailing newline.
